# QuBridge

## 分区算法演示

算法演示页默认暂停在初始画面。GSP、QHSP 及 DQP 的普通拓扑支持六个关键步骤，进度条标出六个编号节点，可连续拖动、点击节点或使用上一步、下一步查看；手动切换步骤会暂停播放。自动播放到最后一步后，会从第一步循环播放，直到用户暂停。切换算法或拓扑后从第一步重新开始。

DQP 的自定义拓扑保留连续动态演示，只显示播放／暂停、重新开始和速度选择。暂停会冻结当前画面，继续播放时从当前位置接续。

播放器使用从原 GIF 提取的静态 WebP 画面，资源位于 `static/image/partition-steps/`。原 GIF 保留；更新原动画后，使用已安装 Pillow 的 Python 运行 `python tools/export_partition_demo.py`，重新生成播放资源和清单。

## 栏目顶部栏

九个栏目共用 `templates/_page_header.html` 与 `static/css/page-header.css`，统一标题、说明、SVG 图标及首页／退出登录入口。各页面通过模板参数设置内容；模拟器保留当前算法名称的动态更新。桌面和窄屏布局共用同一套样式，无需逐页调整。

## 深色导航与页面外观

九个栏目通过 `templates/_site_navigation.html` 共用四组导航：平台概览、量子计算、演示与分析、项目资讯。展开时显示完整名称，分组可单独收起；点击底部“收起导航”切换为 SVG 图标栏，悬停或键盘聚焦显示名称。量子模拟器保留标准、自适应和算法对比子入口，折叠时弹出选项。

`static/js/shell-state.js` 在绘制前恢复桌面导航宽度，`static/js/shell.js` 管理分组、提示、子菜单和手机抽屉。展开／折叠及分组状态保存在浏览器本地；进入新栏目时自动显示其所属分组。账号区固定在底部，菜单在短屏幕中独立滚动。手机端提供导航按钮、遮罩和 Escape 关闭。

`static/css/shell.css` 统一深蓝黑背景、导航、卡片和表单配色，顶部栏使用对应的深色样式；图表文字已适配深色背景。原动画画面和实验图片保留原始配色。维护时请修改共享组件，不再向单个页面添加独立导航事件。

导航折叠后隐藏退出登录入口，只保留底部账户头像；图标和头像在整栏收放时保持水平位置，分类及算法子菜单以连续的高度和透明度过渡展开、收起。九个栏目顶部采用透明背景、细分隔线和分组路径，与页面背景自然衔接。

### 导航动效配置（仅维护人员）

修改项目根目录 `ui_config.py` 的 `NAVIGATION_ANIMATIONS`：`1` 启用，`0` 关闭，保存后重启 QuBridge 服务生效。该开关不提供网页设置入口，配置文件不放在静态资源目录。开关同时控制整栏、分类、算法子菜单及手机抽屉的过渡；系统开启“减少动态效果”时也会关闭导航动效。关闭动效不会改变菜单状态、键盘操作或各栏目原有功能，也不会关闭首页量子动画及算法演示播放。
