# QuBridge 本机运行

在 Windows PowerShell 中，从项目目录运行：

```powershell
.\setup-web.ps1
& .\.web-venv\Scripts\python.exe app.py
```

若自动检测不到 Python，可用 `-PythonPath` 指定 Python 3.10–3.12 的 `python.exe`。当前机器的旧 `.venv` 指向另一位用户的安装路径，请使用新建的 `.web-venv`。项目默认在 `http://127.0.0.1:5000` 启动。

`requirements-web.txt` 只安装当前 Web 应用及其量子分析模块直接需要的依赖。路由页面接收 OpenQASM 2 `.qasm` 文件，服务端解析量子门；页面上的保真度是按演示拓扑和固定误差模型计算的估计值，并非真实设备校准或测量数据。

验证命令：

```powershell
& .\.web-venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 分区算法演示

算法演示页默认暂停在初始画面。GSP、QHSP 及 DQP 的普通拓扑支持六个关键步骤，进度条标出六个编号节点，可连续拖动、点击节点或使用上一步、下一步查看；手动切换步骤会暂停播放。自动播放到最后一步后，会从第一步循环播放，直到用户暂停。切换算法或拓扑后从第一步重新开始。

DQP 的自定义拓扑保留连续动态演示，只显示播放／暂停、重新开始和速度选择。暂停会冻结当前画面，继续播放时从当前位置接续。

播放器使用从原 GIF 提取的静态 WebP 画面，资源位于 `static/image/partition-steps/`。原 GIF 保留；更新原动画后，使用已安装 Pillow 的 Python 运行 `python tools/export_partition_demo.py`，重新生成播放资源和清单。

## QuBridge 架构图

框架页采用单一顶部标题、“交互画布＋组件说明”工作区、独立线路密度工具和精简页脚。页面及节点图标统一使用 SVG。`static/js/framework.js` 管理六节点、六连接以及拖拽、缩放、平移、居中和重置；`static/js/framework-page.js` 管理六个节点的联动说明与密度计算；`static/css/framework.css` 维护布局和深色外观。

点击节点或使用键盘 Enter／空格选择组件，选中描边和关联路径保持显示。三个核心组件原有详细介绍、功能列表与优势数据完整保留在“展开详细说明”中。内容区不足 960px 时说明面板移到画布下方；画布不足 600px 时采用两列三行的纵向流程。用户拖动后的节点位置、主动调整后的视图在窗口和导航尺寸变化时保留，重置恢复当前宽度的默认布局。

线路密度仍按 `CNOT / qubits²` 计算，示例 `15 / 5² = 0.600`。输入保持不小于 1 的整数要求，支持实时更新、按钮／Enter 计算、错误提示与恢复示例；较大或较小结果使用科学计数法。组件切换与结果更新的轻量动效遵循 `PAGE_TRANSITIONS` 和系统减少动态效果设置。

## 栏目顶部栏

九个栏目共用 `templates/_page_header.html` 与 `static/css/page-header.css`，统一标题、说明、SVG 图标及首页／退出登录入口。各页面通过模板参数设置内容；模拟器保留当前算法名称的动态更新。桌面和窄屏布局共用同一套样式，无需逐页调整。

## 深色导航与页面外观

九个栏目通过 `templates/_site_navigation.html` 共用四组导航：平台概览、量子计算、演示与分析、项目资讯。展开时显示完整名称，分组可单独收起；点击底部“收起导航”切换为 SVG 图标栏，悬停或键盘聚焦显示名称。量子模拟器保留标准、自适应和算法对比子入口，折叠时弹出选项。

`static/js/shell-state.js` 在绘制前恢复导航宽度、分类和算法子菜单状态，`static/js/shell.js` 管理分组、提示、子菜单和手机抽屉。选择模拟器算法后再进入其他栏目，三个子入口保持展开；手动收起后也会记住状态，点击模拟器主入口会重新展开。进入新栏目时自动展开并记住其所属分组，避免离开后突然收起。账号区固定在底部，菜单在短屏幕中独立滚动。手机端提供导航按钮、遮罩和 Escape 关闭。

`static/css/shell.css` 统一深蓝黑背景、导航、卡片和表单配色，顶部栏使用对应的深色样式；图表文字已适配深色背景。原动画画面和实验图片保留原始配色。维护时请修改共享组件，不再向单个页面添加独立导航事件。

导航折叠后隐藏退出登录入口，只保留底部账户头像；图标和头像在整栏收放时保持水平位置，分类及算法子菜单以连续的高度和透明度过渡展开、收起。九个栏目顶部采用透明背景、细分隔线和分组路径，与页面背景自然衔接。

导航滚动位置在同一个浏览器标签页内随栏目切换恢复，短屏或展开算法子菜单后切换栏目不会跳回菜单顶部。

### 界面动效配置（仅维护人员）

修改项目根目录 `ui_config.py` 的 `NAVIGATION_ANIMATIONS`：`1` 启用，`0` 关闭，保存后重启 QuBridge 服务生效。该开关不提供网页设置入口，配置文件不放在静态资源目录。开关同时控制整栏、分类、算法子菜单及手机抽屉的过渡；系统开启“减少动态效果”时也会关闭导航动效。关闭动效不会改变菜单状态、键盘操作或各栏目原有功能，也不会关闭首页量子动画及算法演示播放。

同一文件中的 `PAGE_TRANSITIONS` 独立控制栏目切换：`1` 启用内容淡入和轻微位移，`0` 立即显示。它与导航开关可以分别设置；系统开启减少动态效果时两类过渡均关闭。当前默认两个开关均为 `1`，修改后重启服务。

九页在 `<head>` 开头引用 `templates/_page_transition_head.html`，声明过渡策略并等到标题出现后再首次绘制；在页面原样式之后引用 `templates/_shell_assets.html`，统一加载共享资源。`static/css/page-transitions.css` 定义内容过渡并让导航保持原位，`static/js/page-transitions.js` 提供入场回退。浏览器原生跨文档过渡采用 [Chrome 官方文档中的同源导航机制](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document)，不拦截链接、不引入页面缓存或替换各栏目业务脚本。浏览器不支持或慢加载导致原生过渡跳过时，使用内容入场效果；登录、退出、外部链接及页内算法选择保持原有行为。
